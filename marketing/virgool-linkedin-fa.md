# پست فارسی (ویرگول / لینکدین)

> برای ویرگول همین متن + هدینگ‌ها کافیه. برای لینکدین پاراگراف اول و کد اول + لینک ریپو.

---

اگه با PHP کار کرده باشی، حتماً یه بار با تاریخ شمسی کلنجار رفتی: کتابخونه‌های قدیمی که به `strftime()` منسوخ وابسته‌ان، یا کدی که تاریخ رو دستی رشته‌بازی می‌کنه و یه روز عادی مثل ۳۰ اسفند کبیسه می‌ترکوندش.

من **ParsiDate** رو برای همین ساختم — یه کتابخونه مدرن، بدون هیچ وابستگی، مخصوص تاریخ جلالی:

```bash
composer require mahdyaralipor/parsidate
```

```php
use ParsiDate\ParsiDate;

$today = ParsiDate::now();
echo $today->format('l j M Y');      // Panjshanbeh 15 شهریور 1403

ParsiDate::parse('۱۴۰۳/۰۶/۱۵');      // اعداد فارسی هم می‌فهمه

$today->isHoliday();                 // true/false
$today->holidayName();                // "جشن نوروز"
$today->addWorkdays(5);              // ۵ روز کاری بعد (جمعه و تعطیل رسمی رد می‌کنه)
```

چیزایی که برام مهم بود:

- ✅ **بدون dependency** — فقط PHP 8.1+ خالص
- ✅ **Immutable** — هر متد یه نمونه جدید برمی‌گردونه، خبری از side-effect نیست
- ✅ **تعطیلات رسمی ایران built-in** (۱۴۰۰ تا ۱۴۰۶، تک‌تک تاریخ‌ها با تقویم رسمی چک شده) + روزهای کاری
- ✅ **Period** — بازه تاریخی با `foreach`، فیلتر جمعه‌ها/تعطیلات، تقسیم هفتگی و ماهانه
- ✅ **تبدیل هجری قمری** + اعداد فارسی
- ✅ **۱۳۶ تست سبز**

```php
$period = ParsiPeriod::ofMonth(1403, 1);
$period->countWorkdays();   // تعداد روزهای کاری فروردین
foreach ($period->fridays() as $friday) { ... }
```
